## 🚀 Features

- 🌍 Get real-time weather updates for any location.
- 🔄 Fast performance with **Vite**.
- 🔧 Built with **TypeScript** for better type safety.
- 🎨 Fully responsive UI.
- 🛠️ API integration with [Geocoding API](https://geocode.maps.co/) And [Open Metro](https://open-meteo.com/)

---

## ⚡ Tech Stack

- **Frontend:** React + Vite + TypeScript
- **CSS Framework:** Tailwind CSS (or any other framework if used)
- **API:**  [Geocoding API](https://geocode.maps.co/) And [Open Metro](https://open-meteo.com/)

## 🛠️ Installation & Setup

Follow these steps to run the project locally:



### 1 **Clone the Repository**
```sh
npm install -g bun
git clone https://github.com/GamerBhushan/Weather-App-React.git
cd Weather-App-React
```

### 2 **Install Dependencies**
```sh
bun install  
```

### 3 **Set Up API Key**
- Create an account on [Geocoding API](https://geocode.maps.co/) and get your API key.
- Create a `.env` file in the root directory and add:
  ```sh
  VITE_GEOCODE_API_KEY=your_api_key_here
  ```

### 4 **Run the Project**
```sh
bun run dev  
```
- The app will start on **`http://localhost:5173/`** (default Vite port).
